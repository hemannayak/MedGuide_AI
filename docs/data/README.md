# Data

Data documentation, data dictionaries, and dataset descriptions for MedGuide AI.

- [Research resource adoption](RESEARCH_RESOURCE_ADOPTION.md): user-approved
  datasets/models, access constraints, symptom-checker boundaries and evaluation.
- [Resource manifest](research_resources.json): machine-readable source inventory.
- [Medical source audit](MEDICAL_SOURCE_AUDIT.md): local PDF identity, currency,
  rights and provenance findings.
- [Symptom coverage map](SYMPTOM_COVERAGE_MAP.md): source gaps, extraction needs
