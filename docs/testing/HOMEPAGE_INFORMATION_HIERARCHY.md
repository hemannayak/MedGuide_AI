# Homepage information hierarchy refinement

Home now follows introduction → access barriers → interactive product preview → short care journey → language context → safety philosophy → deeper exploration → web/mobile entry.

Distance, Language, and Reliability retain their original statements in a connected editorial sequence rather than generic cards. Native-script examples are introduced by the access challenge. Detailed transcript, speech-service and evaluation information remains on Languages. The homepage no longer duplicates the technical RAG diagram or safety pipeline; Technology, How It Works and Safety retain their detailed explanations and progressive disclosure.

The shared public header removes the language selector, adds existing Home/Technology/Research routes, and gives Sign In a high-contrast paper background. Navigation collapses at 1300px with an independently visible Sign In link, scrollable mobile menu, active states and Escape handling. Language preferences remain available in onboarding and application settings.

Latest steering: the language story is removed from Home only and retained in the Languages route. Hero, authentication and footer now use independently generated portrait/landscape WebP assets. See docs/design/RESPONSIVE_BACKGROUNDS.md for prompts and integration details.
