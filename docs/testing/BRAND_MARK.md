# MedGuide brand mark

An original three-shape SVG combines inward-facing leaves with a rounded cradle: growth, welcome and care. Forest green preserves the existing visual identity. The shared CSS mask supports light footer treatments.

The shared public asset is medguide-mark.svg; app/icon.svg supplies the browser icon. Marketing, authentication, footer and product previews inherit the asset through Brand. Application navigation uses the same mark with a live text wordmark. Existing source artwork is retained.
